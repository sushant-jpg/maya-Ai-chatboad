# Maya

Maya is a polished AI chatbot interface built with vanilla HTML, CSS, and JavaScript.

## Features

- Landing screen with suggestion cards
- Sidebar with search and chat history
- Chat UI with assistant and user bubbles
- Message styling, code blocks, and copy support
- Settings modal with theme and font size controls
- Local storage persistence
- Provider switch for Gemini, OpenAI, OpenRouter, and DeepSeek

## Usage

Open index.html in a browser to use Maya.
